# Animal facial-expression artwork

Created using the built-in imagegen tool from the existing animal sheets. Originals were preserved. Each output is a transparent 1254×1254 PNG with four expression columns. The sprite renderer uses measured per-animal rectangles so tails, ears and feet are not clipped.

### grove

Mode: edit from sprites.png; transparent background.

Saved as mobile/assets/grove-expressions.png.

Prompt:
Edit the animal designs in the attached reference into a production game sprite sheet for grove. Transparent background PNG. EXACT regular 4-column by 4-row grid with 16 equal square cells; each whole animal centered within its own cell with generous padding, no overlap. The animals in ROW order are: yellow chick Pip; green frog Fern; cream rabbit Clover; orange fox Maple. Every row repeats the SAME animal at SAME size and SAME body pose across all four columns. COLUMN 1: happy smiling face, healthy thriving habitat. COLUMN 2: slightly worried eyes and small uneasy mouth, littered habitat. COLUMN 3: sad eyes and downturned mouth, tarnished habitat. COLUMN 4: distressed eyes and frown, polluted habitat. Change facial expressions visibly, keeping the body, color, silhouette and recognizable original design consistent across columns. Crisp pixel art with the same dark outlines as the reference. All eyes and mouths must be on the actual animal face. Do not add text, labels, hearts, separate emotion symbols, scenery, food, props, shadows, borders or grid lines. Only the four named animals repeated in a strict 4x4 grid. Square image.
